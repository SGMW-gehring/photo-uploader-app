开启自动识别？

自动识别会让摄像头一直不停地解码，
耗电快，手机容易发烫，长时间用还可能被系统降频变卡。
建议保持关闭：对准条码点「识别追溯码」（或拍照时自动识别，单次解码几乎不发热）。

关闭水印？

关闭后照片底部不再烧入追溯码 / 拍摄者 / 工位 / 时间，
照片一旦离开本机，就无法再追溯到人和工位。
建议保持开启（水印不影响上传速度，也不影响识别）。
